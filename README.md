# Aryan's Shop

A basic, unstyled React app combining a login page with the `day_6` product catalog and cart. The catalog is loaded from DummyJSON.

## Run

```powershell
npm install
npm run dev
```

- `aryan@gmail.com` — Aryan Saini
- `akash@gmail.com` — Akash

Add products from the dashboard, then open the cart to update quantities and view the total.
